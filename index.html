3. Deep Dives

Splits Generator

Automated split generation for Deep Dives. Allows to identify breakouts by channel, build the granularity for splits, aggregate small splits if needed, and validate all the process is done correctly. Generates inputs for PSO, and metadata to connect with other apps.

Input: AnalyticalDataset, RAE Datafile, VOF Metadata, ModelDetails, ROIs by Channel

Open App

PSO Code

Refactored R Script (modularized) to prepare data and run PSO Algorithm for Deep Dives. Generates pre-optimization and post-optimization validation reports and Side Model Result.

Input: Anlytical Extended, Side Model Mapping, Model Results.zip, ModelDetails

Open Repo
